# Atome Studio — UI/UX Дизайн

Скилл для дизайн-решений проекта Atome Studio.

## Визуальная концепция

**Тема**: Космос / Научная визуализация (Sci-fi monitoring)
**Общий стиль**: Тёмный, минималистичный, с неоновыми акцентами

| `bg-secondary` | `#010410` | Панели, карточки |
| `bg-elevated` | `#050e28` | Поднятые элементы (stat boxes) |

## Типографика

- **Основной шрифт**: `'Courier New', monospace` (sci-fi aesthetic)
- **Размеры**: 7px (micro labels) → 8.5px (подписи) → 9.5px (текст) → 10px (заголовки) → 13px (название) → 20px (цифры)
- **Letter-spacing**: 0.03em–0.22em (uppercase labels)

## Компоненты UI

### Stat Box
- Скруглённые углы: 9px
- Фон: `bg-elevated` с полупрозрачной рамкой
- Label сверху (7px, uppercase), значение снизу (20px, bold, цветное)

### Service Row
- Padding: 6px 7px
- Hover: `rgba(18,55,135,0.14)`
- Точка статуса (5px) + название + тег типа

### Tooltip
- Полупрозрачный тёмный фон с blur
- Рамка цвета платформы
- Скруглённые углы: 10px
- Появление: opacity transition 140ms

### Sparkline
- Высота: 36px
- Градиентная заливка снизу
- Линия 1.3px
- Точка на конце с glow-эффектом

## Принципы UX

1. **Information density** — максимум информации на экране без перегрузки
2. **Glanceable** — статус системы понятен за 1 секунду (цвета, анимации)
3. **Progressive disclosure** — детали по наведению/клику, не на экране постоянно
4. **Consistent color coding** — платформа = цвет, статус = цвет, везде одинаково
5. **Smooth animations** — все переходы плавные, ничего дёрганого

## Для новых компонентов

При создании нового UI-компонента:
1. Используй цвета из палитры выше
2. Следуй стилю `atomic_monitor.html` (reference)
3. Скруглённые углы: 7–10px
4. Полупрозрачные фоны и рамки
5. Uppercase labels с letter-spacing
