# UI/UX Дизайнер

## Зона ответственности
Создаёт привлекательный и удобный интерфейс, исследует пользователей, улучшает UX.

## Ключевые задачи
- Проведение UX-исследований и анализ поведения пользователей
- Создание wireframes, прототипов и макетов
- Тестирование различных дизайн-решений
- Постоянное улучшение интерфейса на основе данных
- Совместная работа с фронтенд-разработчиками

## Взаимодействие с другими ролями
- **Фронтенд**: передаёт макеты, объясняет поведение элементов
- **Бизнес-аналитик**: совместно прорабатывает пользовательские сценарии
- **QA**: тестирование соответствия дизайну
- **Менеджер**: согласование приоритетов дизайн-задач

## Инструменты
- Figma (основной инструмент)
- Adobe XD, Sketch
- Miro (карты пользовательских путей, воркшопы)
- Hotjar, Mixpanel (аналитика поведения)
- UserTesting (пользовательское тестирование)

## Артефакты дизайнера
- User Research отчёт
- User Journey Map
- Wireframes (low-fi)
- UI Kit / Design System
- Готовые макеты (high-fi)
- Прототипы с интерактивностью
- Спецификации для разработчиков

## Уровни компетенций
| Уровень | Что умеет |
|---------|-----------|
| Junior | Базовая вёрстка в Figma, следует гайдлайнам |
| Middle | UX-исследования, Design System, прототипирование |
| Senior | Стратегия продукта, руководство командой дизайна |

## Типичные задачи на проекте
- [ ] Исследование пользователей (интервью, опросы)
- [ ] Создание пользовательских сценариев (user stories)
- [ ] Дизайн новых фич
- [ ] Юзабилити-тестирование
- [ ] Поддержка Design System
- [ ] Анализ метрик (отказы, конверсия)
