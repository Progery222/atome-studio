# DevOps Инженер

## Зона ответственности
Интегрирует разработку и эксплуатацию, автоматизирует деплой, мониторинг и инфраструктуру.

## Ключевые задачи
- Настройка CI/CD пайплайнов
- Управление серверной инфраструктурой
- Автоматизация процессов развёртывания
- Мониторинг и реагирование на сбои (24/7)
- Оптимизация инфраструктуры
- Обеспечение безопасности инфраструктуры

## Взаимодействие с другими ролями
- **Бэкенд**: настройка окружений, помощь с деплоем
- **Тимлид**: согласование инфраструктурных изменений
- **QA**: настройка тестовых окружений
- **Все**: инцидент-менеджмент при сбоях

## Технологический стек
**Контейнеризация:**
- Docker, Docker Compose
- Kubernetes (K8s)

**CI/CD:**
- GitLab CI, GitHub Actions
- Jenkins, TeamCity

**Облака:**
- AWS (EC2, S3, RDS, Lambda)
- GCP, Azure

**Мониторинг:**
- Prometheus + Grafana
- ELK Stack (Elasticsearch, Logstash, Kibana)
- Sentry

**IaC (Infrastructure as Code):**
- Terraform
- Ansible

## Уровни компетенций
| Уровень | Что умеет |
|---------|-----------|
| Junior | Docker, базовый Linux, CI/CD пайплайны |
| Middle | K8s, облака, мониторинг, Terraform |
| Senior | Архитектура инфраструктуры, оптимизация затрат |

## Типичные задачи на проекте
- [ ] Настройка CI/CD для новой фичи
- [ ] Создание и управление окружениями (dev, staging, prod)
- [ ] Настройка алертов мониторинга
- [ ] Оптимизация времени сборки
- [ ] Управление секретами (Vault, AWS Secrets Manager)
- [ ] Disaster Recovery планирование

## SLA метрики, за которые отвечает DevOps
- Uptime: 99.9%+
- Время деплоя: минуты, не часы
- Время восстановления (RTO): < 1 час
- Время обнаружения инцидента: < 5 минут
