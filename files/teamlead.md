# Тимлид (Team Lead)

## Зона ответственности
Руководит небольшим подразделением, координирует работу и несёт ответственность за результаты команды.

## Ключевые задачи
- Обеспечение коммуникации между участниками команды и менеджерами
- Решение оперативных вопросов
- Контроль выполнения задач
- Участие в технических обсуждениях
- Помощь команде при трудностях
- Обучение и менторинг менее опытных сотрудников
- Принятие ключевых решений в процессе разработки

## Взаимодействие с другими ролями
- **Менеджер**: получает задачи сверху, отчитывается о прогрессе
- **Разработчики**: распределяет задачи, проводит code review, помогает с блокерами
- **QA**: согласует критерии готовности задачи
- **DevOps**: координирует деплой и инфраструктурные изменения

## Навыки (hard skills)
- Глубокие технические знания в стеке команды
- Опыт code review
- Понимание архитектурных решений
- Ведение технической документации

## Навыки (soft skills)
- Лидерство и мотивация
- Чёткая коммуникация
- Тайм-менеджмент
- Умение давать конструктивную обратную связь

## Типичные задачи на проекте
- [ ] Разбивка эпиков на задачи
- [ ] Daily standup с командой
- [ ] Code review
- [ ] 1-on-1 с членами команды
- [ ] Оценка сложности задач (story points)
- [ ] Устранение блокеров

## Уровни: Junior TL → Middle TL → Senior TL → Engineering Manager
