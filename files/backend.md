# Бэкенд-разработчик (Backend Developer)

## Зона ответственности
Серверная часть, бизнес-логика, базы данных, API, безопасность и производительность системы.

## Ключевые задачи
- Разработка серверной логики приложения
- Проектирование и работа с базами данных
- Создание и поддержка API (REST, GraphQL, gRPC)
- Интеграция с внешними сервисами
- Обеспечение безопасности, масштабируемости и производительности
- Работа с высокими нагрузками

## Взаимодействие с другими ролями
- **Фронтенд**: проектирует и документирует API
- **DevOps**: согласует деплой, конфигурацию окружения
- **QA**: помогает с воспроизведением и исправлением серверных багов
- **Бизнес-аналитик**: уточняет бизнес-логику

## Технологический стек
**Языки:**
- Python (Django, FastAPI, Flask)
- Node.js (Express, NestJS)
- Java (Spring Boot)
- Go, PHP, Ruby — по запросу

**Базы данных:**
- Реляционные: PostgreSQL, MySQL
- NoSQL: MongoDB, Redis
- Очереди: RabbitMQ, Kafka

**Инфраструктура:**
- Docker
- Базовые знания облаков (AWS/GCP/Azure)
- CI/CD пайплайны

## Уровни компетенций
| Уровень | Что умеет |
|---------|-----------|
| Junior | CRUD, базовый SQL, простые API |
| Middle | Сложные запросы, кэширование, тесты, очереди |
| Senior | Архитектура систем, микросервисы, нагрузочное тестирование |

## Типичные задачи на проекте
- [ ] Разработка эндпоинтов API
- [ ] Миграции базы данных
- [ ] Написание unit/integration тестов
- [ ] Оптимизация медленных запросов
- [ ] Настройка авторизации (JWT, OAuth)
- [ ] Логирование и мониторинг
