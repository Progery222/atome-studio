# Фронтенд-разработчик (Frontend Developer)

## Зона ответственности
Создаёт клиентскую часть приложения: UI, интерактивность, адаптивность.

## Ключевые задачи
- Реализация интерфейса по макетам дизайнера
- Перевод макетов в интерактивные элементы
- Оптимизация под разные устройства и браузеры
- Обеспечение производительности интерфейса
- Реакция на обратную связь пользователей

## Взаимодействие с другими ролями
- **UI/UX дизайнер**: получает макеты, обсуждает реализуемость
- **Бэкенд**: согласует формат API, интеграция
- **QA**: передаёт на тестирование, исправляет баги
- **Тимлид**: получает задачи, отчитывается о прогрессе

## Технологический стек
**Обязательно:**
- HTML5, CSS3
- JavaScript (ES6+)
- Один из фреймворков: React / Vue / Angular

**Дополнительно:**
- TypeScript
- State management: Redux / Zustand / Pinia
- Сборщики: Webpack / Vite
- Тестирование: Jest, Cypress
- CSS-методологии: BEM, CSS Modules, Tailwind

## Уровни компетенций
| Уровень | Что умеет |
|---------|-----------|
| Junior | HTML/CSS/JS, базовый React, работа по макету |
| Middle | Оптимизация, TypeScript, тесты, работа с API |
| Senior | Архитектура фронтенда, менторинг, сложные паттерны |

## Типичные задачи на проекте
- [ ] Верстка компонентов по Figma
- [ ] Интеграция с REST/GraphQL API
- [ ] Адаптивная вёрстка (mobile, tablet, desktop)
- [ ] Оптимизация производительности (Lighthouse)
- [ ] Code review
- [ ] Исправление кросс-браузерных багов
