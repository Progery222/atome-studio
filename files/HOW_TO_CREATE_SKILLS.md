# 📘 Как создавать Skills самому

## Что такое скилл?

Скилл — это папка с файлом `SKILL.md`, который Claude читает перед выполнением задачи.
Он содержит инструкции, шаблоны и правила, чтобы ответы были точными и предсказуемыми.

---

## Структура скилла

```
название-скилла/
├── SKILL.md          ← обязательный (инструкции)
└── references/       ← опционально (дополнительные файлы)
    ├── тема1.md
    └── тема2.md
```

---

## Анатомия SKILL.md

```markdown
---
name: название-скилла
description: КОГДА использовать скилл и ЧТО он делает.
             Пиши конкретно — включай ключевые слова,
             которые пользователь может написать.
             Будь "настойчивым": "Используй при любом упоминании X"
---

# Заголовок скилла

## Раздел 1: Контекст / Принципы
[Объясни Claude, что нужно знать]

## Раздел 2: Инструкции / Алгоритм
[Пошаговый процесс или правила]

## Раздел 3: Шаблоны / Примеры
[Готовые форматы для вывода]

## Дополнительно
Для деталей читай: `references/тема.md`
```

---

## Правила написания хорошего скилла

### ✅ DO — делай так:
- **Конкретные ключевые слова в description** — Claude триггерит скилл по ним
- **Пошаговые инструкции** — не просто "сделай хорошо", а "шаг 1, шаг 2..."
- **Шаблоны вывода** — покажи, в каком формате ты хочешь ответ
- **Ссылки на references** — выноси объёмные данные в отдельные файлы
- **До 500 строк** в основном SKILL.md

### ❌ DON'T — не делай так:
- Слишком общее description ("помогает с командой") — плохо триггерит
- Всё в одном файле на 1000+ строк — трудно читать
- Без примеров — Claude не понимает нужный формат

---

## Пример минимального скилла

```markdown
---
name: sprint-planner
description: Используй при планировании спринтов, составлении беклога,
             оценке задач. Активируй при словах: спринт, беклог, 
             планирование, story points, итерация.
---

# Sprint Planner

## Правила планирования
1. Спринт = 2 недели
2. Ёмкость команды = X story points
3. Приоритет: P0 → P1 → P2

## Формат задачи
- **Название**: [глагол + существительное]
- **Роль**: [кто делает]
- **Оценка**: [S=1pt / M=3pt / L=5pt]
- **Зависимости**: [что должно быть готово]
```

---

## Как установить скилл в Claude

1. Создай папку с SKILL.md на своём компьютере
2. В интерфейсе Claude зайди в **Settings → Skills**
3. Загрузи папку или `.skill` файл
4. Скилл появится в списке доступных

---

## Советы по улучшению

- Тестируй: попроси Claude выполнить задачу с активным скиллом
- Если не триггерится — добавь больше ключевых слов в description
- Если ответ не тот формат — добавь явный шаблон в SKILL.md
- Итерируй: улучшай скилл на основе реальных ответов

---

## Чек-лист перед финализацией

- [ ] Frontmatter (name + description) заполнен
- [ ] Description содержит ключевые слова-триггеры
- [ ] Есть чёткие инструкции/алгоритм
- [ ] Есть шаблон ожидаемого вывода
- [ ] SKILL.md < 500 строк
- [ ] Ссылки на references корректны (если есть)
