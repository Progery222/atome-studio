# Бизнес-аналитик (Business Analyst)

## Зона ответственности
Связывает IT и бизнес: анализирует потребности бизнеса и переводит их в технические требования.

## Ключевые задачи
- Проведение исследований и интервью с клиентами
- Формирование требований к продукту
- Перевод бизнес-требований в технические задания
- Контроль соответствия продукта бизнес-целям
- Работа с заинтересованными сторонами (стейкхолдерами)

## Взаимодействие с другими ролями
- **Менеджер**: совместно формирует scope проекта
- **Разработчики**: объясняет бизнес-логику, уточняет требования
- **QA**: предоставляет критерии приёмки
- **UI/UX**: участвует в исследовании пользователей

## Артефакты
- BRD (Business Requirements Document)
- FRD (Functional Requirements Document)
- Use Case / User Stories
- BPMN-диаграммы бизнес-процессов
- Глоссарий предметной области
- Acceptance Criteria

## Инструменты
- Confluence (документация)
- Miro (диаграммы процессов)
- BPMN-инструменты: Camunda, Lucidchart
- Jira (управление требованиями)

## Типичные задачи на проекте
- [ ] Проведение интервью со стейкхолдерами
- [ ] Написание User Stories с критериями приёмки
- [ ] Создание AS-IS / TO-BE процессов
- [ ] Уточнение требований с командой разработки
- [ ] Анализ и приоритизация беклога
- [ ] Валидация реализованных фич с бизнесом
