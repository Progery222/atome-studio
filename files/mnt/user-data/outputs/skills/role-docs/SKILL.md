# Role Documentation Skill

Скилл для создания качественной документации по ролям IT-команды.

## Типы документов

| Документ | Когда нужен |
|----------|-------------|
| Job Description (JD) | При найме нового сотрудника |
| Должностная инструкция | Внутренний документ с обязанностями |
| Матрица компетенций | Оценка и развитие сотрудников |
| RACI по роли | Для новых проектов |
| Профиль должности | Внутренняя карьерная документация |

## Шаблон Job Description

```markdown
## [Название роли] — [Название компании]

### О нас
[Краткое описание компании и продукта]

### Чем предстоит заниматься
[5-8 конкретных задач из references/<роль>.md]

### Что мы ожидаем
**Обязательно:**
- [Hard skill 1]
- [Hard skill 2]
- [Опыт X лет]

**Будет плюсом:**
- [Дополнительный навык]

### Soft skills
- [Коммуникация / Самостоятельность / Инициативность]

### Что предлагаем
- [Условия работы]
- [Развитие]
- [Компенсация]
```

## Матрица компетенций (шаблон)

| Компетенция | Junior | Middle | Senior |
|------------|--------|--------|--------|
| [Навык 1]  | Базово | Уверенно | Экспертно |
| [Навык 2]  | Знает  | Применяет | Обучает |

## Как использовать этот скилл

1. Определи роль (см. список в `it-team/SKILL.md`)
2. Открой нужный файл из `it-team/references/`
3. Используй шаблон выше
4. Адаптируй под конкретный проект и стек
