# Onboarding Skill

Скилл для быстрой и качественной адаптации новых участников IT-команды.

## Структура онбординга

### День 1: Welcome
- [ ] Доступы к инструментам (Jira, Confluence, Git, Slack)
- [ ] Знакомство с командой (структура, роли)
- [ ] Обзор проекта и продукта
- [ ] Встреча с тимлидом: задачи, ожидания, процессы

### Неделя 1: Погружение
- [ ] Изучение документации проекта
- [ ] Настройка локального окружения
- [ ] Первая маленькая задача (good first issue)
- [ ] Знакомство с кодовой базой / дизайн-системой
- [ ] Встреча с менеджером: бизнес-контекст

### 30 дней: Самостоятельность
- [ ] Выполнение задач без постоянной помощи
- [ ] Участие в code review / design review
- [ ] Понимание бизнес-процессов проекта
- [ ] Check-in с тимлидом: обратная связь

### 60 дней: Вклад
- [ ] Предложение улучшений процессов
- [ ] Менторство других новичков (при наличии)
- [ ] Участие в планировании спринтов
- [ ] Обратная связь по онбордингу

### 90 дней: Полная интеграция
- [ ] Самостоятельное ведение задач
- [ ] Участие в технических обсуждениях
- [ ] Performance review

## Шаблоны онбординг-документов по ролям

### Для разработчиков (Frontend / Backend)
Используй `it-team/references/frontend.md` или `it-team/references/backend.md`

Дополнительно включи:
- Стек технологий проекта
- Git-flow и правила работы с ветками
- Процесс code review
- Как запустить проект локально
- Куда задавать вопросы

### Для QA
Используй `it-team/references/qa.md`

Дополнительно включи:
- Тест-план проекта
- Как заводить баги в Jira
- Где находятся тест-кейсы
- Окружения для тестирования

### Для DevOps
Используй `it-team/references/devops.md`

Дополнительно включи:
- Схема инфраструктуры
- Runbook для типовых инцидентов
- Доступы к мониторингу
- Процесс деплоя

### Для дизайнеров
Используй `it-team/references/uiux.md`

Дополнительно включи:
- Доступ к Figma и Design System
- Процесс согласования макетов
- Инструменты аналитики

## Формат Welcome-документа

При создании онбординг-материалов используй эту структуру:

```
# Welcome в команду [Название проекта]!

## О проекте
[Краткое описание]

## Наша команда
[Список ролей и имён]

## Твоя роль
[Что ожидается]

## Инструменты и доступы
[Список]

## Первые шаги
[Чеклист]

## К кому обращаться
[Контакты по темам]
```
