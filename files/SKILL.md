# IT Team Skill

Этот скилл содержит полное описание ролей IT-команды и правила работы с ними.

## Состав команды

### Основные роли
| Роль | Файл с деталями |
|------|----------------|
| Тимлид | `references/teamlead.md` |

| Бэкенд-разработчик | `references/backend.md` |

## Как использовать этот скилл

1. **Распределение задач** — читай `references/<роль>.md` для нужного специалиста
2. **Онбординг** — используй скилл `onboarding`
3. **Документация** — используй скилл `role-docs`
4. **Подбор команды** — см. раздел "Принципы подбора" ниже

## Принципы подбора IT-команды

- Начинай с чёткого определения **целей проекта**, задач, сроков и бюджета
- Составь список нужных ролей и уровней компетенций
- Отдавай предпочтение специалистам с **опытом в нужной предметной области**
- Используй **тестовые задания / live coding** для оценки технических навыков
- Оценивай **soft skills**: коммуникация, умение работать в команде, стремление к развитию
- Подбор — двусторонний процесс: кандидат тоже выбирает тебя

## Быстрая матрица ответственностей

| Зона | Ответственный |
|------|--------------|
| Клиентский интерфейс | Фронтенд + UI/UX |
| Серверная логика и API | Бэкенд |
| Качество и стабильность | QA |
| Инфраструктура и деплой | DevOps |
| Управление проектом | Менеджер + Тимлид |
| Требования от бизнеса | Бизнес-аналитик |
| Документация | Технический писатель |
| Продажи и клиенты | Сейлз-менеджер |
