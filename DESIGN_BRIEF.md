# Atome Studio — Дизайн-бриф

> Документ для дизайнера. Описывает визуальный стиль и все экраны панели управления TikTok-фермой.

---

## Что это за продукт

Панель управления для операторов, которые запускают TikTok-аккаунты в промышленных масштабах. На ферме — сотни телефонов, каждый держит несколько аккаунтов. Система автоматически генерирует видео и публикует их по расписанию. Dashboard даёт оператору полный контроль: видеть статусы, запускать генерацию, следить за очередью.

**Пользователи:** технические операторы, не широкая аудитория. Им важна плотность информации и скорость работы — не красота ради красоты.

**Только desktop.** Минимальная ширина экрана 1280px. Мобильная версия не нужна.

---

## Общий визуальный стиль

**Тема:** Sci-fi, космос, технологичность. Как если бы NASA или SpaceX делали внутренний инструмент.

**Настроение:** Тёмный, сдержанный, профессиональный. Цвета используются только для передачи информации — статус, тип, приоритет. Никакого декора ради декора.

**Референсы для вдохновения:**
- Bloomberg Terminal (плотность информации)
- SpaceX Mission Control (тёмная тема, статусы)
- Vercel Dashboard (чистота, минимализм)
- Linear (типографика, таблицы)

## Цвета

### Фоны

| Назначение | Цвет |
|---|---|
| Основной фон (весь экран) | `#01030a` — почти чёрный с синим отливом |
| Фон панелей и карточек | `#010410` — чуть светлее |
| Фон поднятых элементов (виджеты, блоки) | `#050e28` — тёмно-синий |
| Hover на строках таблицы | очень слабый синий, ~10% opacity |

### Акцентные цвета — сервисы

Каждый из трёх сервисов системы имеет свой цвет. Он используется везде, где упоминается этот сервис.

| Сервис | Цвет | Где используется |
|---|---|---|
| **SportZavod** (генерирует спортивные видео) | зелёный `#22c55e` | атом в галактике, бейдж, рамка карточки |
| **content-zavod** (генерирует универсальные видео) | голубой `#38bdf8` | то же самое |
| **Orchestrator** (управляет телефонами) | фиолетовый `#a78bfa` | то же самое |

### Статусы

| Статус | Цвет | Использование |
|---|---|---|
| active / online | зелёный `#22c55e` | телефоны, аккаунты, сервисы |
| warmup / degraded | жёлтый `#eab308` | телефон в прогреве, сервис с проблемами |
| offline / error | красный `#ef4444` | всё, что не работает |
| paused | серый `#6b7280` | поставлено на паузу вручную |
| banned | красный + бейдж "BAN" | аккаунт или телефон заблокирован TikTok |

### Текст

Весь текст — белый или голубоватый, на тёмном фоне. Три уровня яркости:

- **Основной текст** — голубовато-белый, ~65% opacity. Для всего тела.
- **Второстепенный** — приглушённый синий, ~38% opacity. Для подписей, лейблов, вспомогательной информации.
- **Акцентный** — светло-голубой, ~60% opacity. Для заголовков секций.

## Типографика

**Шрифт:** `Courier New` или любой моноширинный (JetBrains Mono, IBM Plex Mono). Это намеренно — создаёт ощущение терминала/инженерного инструмента.

**Размерная шкала:**
- Микро-лейблы (названия полей, заголовки колонок таблиц) — 7–8px, **UPPERCASE**, с увеличенным межбуквенным расстоянием
- Основной текст — 9.5–10px
- Заголовки страниц — 13px, uppercase
- Большие цифры в виджетах — 20px, bold, цветные

**Боковое меню (sidebar):**
- Ширина 64px, слева
- Фон чуть темнее основного

- Сверху: логотип / иконка приложения
- Снизу: аватар пользователя + кнопка выхода
- Активный пункт подсвечивается

**Иконки меню (сверху вниз):**
1. Галактика (главная)
2. Телефоны
3. Аккаунты
4. Генерация
5. Очередь
6. Видеотека
7. Клиенты *(только для super admin)*

## Переиспользуемые компоненты

### Виджет-статистика (Stat Widget)

Небольшой прямоугольный блок (~140×80px). Используется в нескольких местах.

- Фон `#050e28`, скруглённые углы ~10px
- Тонкая рамка, слабо-синяя, полупрозрачная
- Сверху: маленький лейбл (7px, uppercase, приглушённый)
- Снизу: большое число (20px, bold, цветное — зелёный для хороших метрик, белый для нейтральных)

Пример: `ПУБЛИКАЦИЙ СЕГОДНЯ` / `247`

---

### Индикатор статуса (Status Dot)

Цветной круг 8px рядом с названием. Цвет — по таблице статусов выше.
- Для `active` — слабое свечение (glow)
- Для `banned` — мигание

---

### Полоска здоровья (Health Bar)

Горизонтальный прогресс-бар, ~80px в ширину, 6px в высоту.
- >80% — зелёный
- 50–80% — жёлтый
- <50% — красный

---

### Кнопки

- **Основная (зелёная):** тёмно-зелёный фон (~15% opacity) + зелёная рамка. Текст белый. Для основных действий (запустить, создать).
- **Опасная (красная):** то же самое, но красная. Для деструктивных действий (остановить, удалить).
- **Вторичная (прозрачная):** без фона, слабая рамка. Для второстепенных действий (отмена, фильтр).

---

### Таблицы

- Строки разделены тонкой линией ~10% opacity
- Hover на строку — слабый синий оверлей
- Заголовки колонок: uppercase, 7px, приглушённый цвет
- Кликабельная строка: курсор pointer, нет underline

---

### Тултип

Появляется при наведении. Полупрозрачный тёмный фон + размытие (backdrop-blur). Рамка цвета элемента. Скруглённые углы. Появляется за 140ms.

---

### Модалка

Тёмная полупрозрачная подложка на весь экран. Модалка по центру ~500px шириной. Фон `#050e28`, рамка слабо-синяя. Появляется с лёгким scale-анимацией (от 95% до 100%).

## Экраны

---

### 1. Галактика (главная, `/`)

**Это самый важный и визуально уникальный экран.** Sidebar здесь не нужен — экран полностью занят 3D-визуализацией.

**Что видит пользователь:**

Тёмный космос с точками-звёздами. В центре — светящееся ядро системы. Вокруг него по трём эллиптическим орбитам летают три атома-планеты — каждый представляет один сервис:
- SportZavod — зелёный атом
- content-zavod — голубой атом
- Orchestrator — фиолетовый атом

Цвет атома отражает статус сервиса: если сервис лежит — атом становится красным.

**Поверх галактики — 4 виджета** (в левом нижнем углу или по нижнему краю):
- Публикаций сегодня
- Телефонов онлайн (например 87/100)
- Аккаунтов активных (142/160)
- Заданий в работе (3 job)

**Взаимодействие:**
- Навести на атом → тултип с названием сервиса, статусом и ключевой метрикой
- Кликнуть на атом → справа выезжает боковая панель с деталями сервиса

---

### 2. Ферма телефонов (`/phones`)

**Что показывает:** все телефоны с их текущим статусом.

**Верхняя полоса:**
- Заголовок "Ферма телефонов"
- Счётчики: ● 87 онлайн / ⚠ 5 прогрев / ○ 8 офлайн / ✕ 0 забанено
- Кнопки: `[+ Добавить]` `[Фильтр]`

**Фильтр по группам** (под счётчиками): `[Все] [batch_1] [sports] [lifestyle] [test]`

**Основное содержимое — сетка карточек** (4–5 в ряд):

Каждая карточка телефона:
```
┌──────────────────┐
│ ● active         │  ← индикатор статуса (цветной)
│ phone_001        │  ← ID телефона
│ @luna_fashion_01 │  ← username аккаунта (если есть)
│ ♥ ████████░ 95%  │  ← health score (прогресс-бар)
│ 3 поста сегодня  │
│                  │
│ [Пауза]          │  ← кнопка действия
└──────────────────┘
```

Рамка карточки — цвет статуса (зелёная/жёлтая/красная), полупрозрачная.
Если телефон не подключён по ADB — предупреждение ⚠ на карточке.

---

### 3. Детальная страница телефона (`/phones/:id`)

**Верхняя строка:** `← Назад` | `phone_001` | `● active` | `Samsung SM-G780G` | `batch_1`

Страница делится на две зоны:

**Левая колонка:**
- Параметры: статус, модель, ADB serial, группа, день прогрева (3/30)
- Кнопки действий: `[Пауза]` `[Возобновить]` `[Стоп]`

**Правая колонка:**
- График health_score за последние 7 дней (линейный, маленький)
- Статистика: посты сегодня, действий сегодня
- Список задач, назначенных на этот телефон (мини-список очереди)

**Снизу на всю ширину:**
Лог последних 20 действий. Каждая строка: время + описание события + иконка (✅ ❌ ⚠).

### 4. Аккаунты (`/accounts`)

**Верхняя строка:** заголовок + `[+ Создать]` + `[Импорт Google Sheets]` + поиск + фильтр по нише

**Основное содержимое — таблица:**

| Аккаунт | Телефон | Ниша | Health | Статус | Постов сегодня |
|---|---|---|---|---|---|
| @luna_fashion_01 | phone_001 | fashion | ████░ 95% | ● active | 3 |
| @layla_ceramic | phone_002 | ceramic | ███░░ 88% | ● active | 1 |
| @nba_acc_01 | phone_007 | sports | █████ 100% | ⚠ warmup | 0 |

- Клик на строку → переход на детальную страницу аккаунта
- Health показывается цветным прогресс-баром

---

### 5. Модалка — Создание аккаунта

Открывается по кнопке `[+ Создать]` на странице аккаунтов.

Поля:
- Username (текст)
- Телефон (выпадающий список — список телефонов)
- Ниша (выпадающий список: sports, lifestyle, fashion, fitness...)
- Источники контента (мультиселект с чекбоксами: SportZavod / content-zavod)
- Частота публикаций (слайдер от 4 до 24 часов, показывает значение)
- Временная зона (выпадающий список)
- HeyGen Avatar ID (текст — появляется только если выбран SportZavod)

Кнопки снизу: `[Отмена]` `[Создать аккаунт →]`

### 6. Детальная страница аккаунта (`/accounts/:id`)

**Верхняя строка:** `← Назад` | `@luna_fashion_01` | `● active` | `phone_001`

Страница — две колонки:

**Левая:**
- Все параметры аккаунта с возможностью редактировать по клику (inline edit)
- Кнопка `[Запустить генерацию для этого аккаунта]`
- Текущая позиция в очереди публикаций: "Следующий пост через 2ч 15м"

**Правая:**
- График публикаций за последние 30 дней (столбчатый или линейный)
- График health_score за последние 30 дней

**Снизу:** горизонтальная лента из последних 3–5 видео с превью-миниатюрой, датой и статусом.

### 7. Генерация контента (`/generate`)

**Шаг 1 — Форма запуска:**

Страница не таблица, а форма-карточка по центру (~600px шириной).

```
Сервис:
  ○ SportZavod — спортивные видео (NBA, UFC, Football)
  ● content-zavod — универсальные видео (любая тема)

Аккаунты:                              [Все] [По нише ▾]
┌────────────────────────────────────────────────┐
│ ☑ @nba_acc_01   phone_007   sports             │
│ ☑ @nba_acc_02   phone_003   sports             │
│ ☐ @luna_01      phone_001   lifestyle          │
└────────────────────────────────────────────────┘

Видео на аккаунт:  [1]  [2]  [3]  [5]

Тема (только для content-zavod):
[____________________________________________]

              [  Запустить генерацию →  ]
```

**Шаг 2 — Прогресс (после нажатия кнопки):**

Форма заменяется экраном прогресса:

```
Генерация запущена

████████████████████░░░░░░░░░░  68%

  @nba_acc_01   Этап 4 из 7: рендеринг   ⏳
  @nba_acc_02   Завершено                ✅
  @nba_acc_03   Ожидание...              ○

                [Отмена]    [Перейти в очередь →]
```

Прогресс обновляется автоматически каждые 5 секунд.

### 8. Очередь публикаций (`/queue`)

**Верхняя строка:**
- Заголовок
- Счётчики: Запланировано: 48 | Опубликовано: 12 | ❌ Ошибок: 3
- Фильтр по статусу

**Основное содержимое — вертикальный список строк:**

Каждая строка — одна задача публикации:

```
┌──────────────────────────────────────────────────────────┐
│ [превью] @nba_acc_01   phone_007   ● публикуется сейчас  │
│          "NBA Finals highlights смотри лучшие моменты..." │
│          → 14:30 EST                                      │
└──────────────────────────────────────────────────────────┘
```

Статусы строк:
- `● публикуется сейчас` — строка подсвечена зелёным, пульсирующая точка
- `⏰ через 2ч 15м` — таймер обратного отсчёта
- `✅ опубликовано в 11:30` + показатели (views за 1 час)
- `❌ ошибка` + кнопка `[Повторить]`

Для scheduled задач — кнопка `[✕]` удалить из очереди (появляется при наведении).

## Анимации и взаимодействия

- **Все переходы:** 200–300ms, ease
- **Атомы в галактике:** плавное непрерывное вращение по орбитам
- **"Публикуется сейчас":** строка в очереди — мягкое зелёное свечение + пульсирующая точка
- **Прогресс-бар генерации:** плавное заполнение, не прыжками
- **Модалки:** появляются с лёгким увеличением (scale 0.95 → 1.0) + затемнение фона
- **Числа в виджетах:** при изменении — короткая анимация счётчика
- **Hover на карточке телефона:** лёгкое поднятие (translateY -2px) + усиление рамки
